# Access Hub

Access Hub is a modular Flask service for user accounts, JWT authentication,
session revocation, role-based authorization, and account security.

Use this documentation to run the service, understand its architecture, and
integrate with its HTTP API.

## Start here

- Follow the [setup guide](setup.md) to run the application locally.
- Read the [architecture guide](architecture.md) to understand its modules and
  request flow.
- Explore the interactive OpenAPI reference for exact requests and responses.
